# CV4Ecology South Africa workshop website

One-page GitHub Pages website for:

Computer Vision for Ecology in South Africa
22–26 February 2027
AIMS Muizenberg, South Africa

## Deploy on GitHub Pages

1. Create/open the repository `cv4ecology-sa.github.io`.
2. Upload `index.html` and `style.css` to the root of the repository.
3. Commit the changes to the `main` branch.
4. In Settings → Pages, use `Deploy from a branch`, `main`, `/ (root)`.
5. The site should appear at https://cv4ecology-sa.github.io/

## Before publishing

Replace the `Application form coming soon` link in `index.html` with the URL of the actual application form.

You can also replace the programme placeholders and add organiser/partner logos later.
