# Images

Drop your photos here using these file names. Until a file exists, the site shows a labelled placeholder in its place.

| File | Where it appears | Suggested shape |
|---|---|---|
| `hero.jpg` + `hero-small.jpg` | Full-width background of the top banner; the small one is used on phones | Landscape, subject on the right; ~2400 px and ~1200 px wide |
| `camera-trap.jpg` | Image strip under "About" | Landscape, 4:3 (e.g. 1200×900) |
| `drone.jpg` | Image strip under "About" | Landscape, 4:3 |
| `satellite.jpg` | Image strip under "About" | Landscape, 4:3 |
| `venue.jpg` | Practical information | Portrait, 4:5 |
| `logo-1.png` … `logo-4.png` | Organisers & partners row | Transparent PNG or SVG-like PNG |

After adding a photo, edit `index.html` to fill in its `alt="..."` text.
Keep photos under ~500 KB each so the page loads quickly.
