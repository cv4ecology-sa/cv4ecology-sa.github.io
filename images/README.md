# Images

Drop your photos here using these file names. Until a file exists, the site shows a labelled placeholder in its place.

| File | Where it appears | Suggested shape |
|---|---|---|
| `hero.jpg` | Top of the page, next to the title (Fig. 1) | Portrait, 4:5 (e.g. 1200×1500) |
| `camera-trap.jpg` | Image strip under "About" (Fig. 2) | Landscape, 4:3 (e.g. 1200×900) |
| `drone.jpg` | Image strip under "About" (Fig. 3) | Landscape, 4:3 |
| `satellite.jpg` | Image strip under "About" (Fig. 4) | Landscape, 4:3 |
| `venue.jpg` | Practical information (Fig. 5) | Portrait, 4:5 |
| `logo-1.png` … `logo-4.png` | Organisers & partners row | Transparent PNG or SVG-like PNG |

After adding a photo, edit `index.html` to fill in its `alt="..."` text and update the figure caption.
Keep photos under ~500 KB each so the page loads quickly.
